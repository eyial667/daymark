# Roadmap

## Slice 1 — Today foundation

- Local task creation and completion
- SQLite persistence and migrations
- Explainable priority ordering
- Native desktop shell

## Slice 2 — Planning essentials

- Edit, postpone, and restore completed tasks
- Inbox processing
- Daily capacity and overload warnings
- Recurring tasks
- Keyboard command palette

## Slice 3 — Connected mind map

- Long-term goals and dated milestones (foundation complete)
- Life areas, projects, and links between goals and tasks
- Task dependencies and blocked states
- Zoomable native graphics scene
- Shared selection between the map and Today queue

## Slice 4 — Focus and review

- Focus sessions and timers
- Planned versus actual time
- Evening and weekly reviews
- Postponement and estimation insights

## Slice 5 — Integrations and distribution

- Calendar adapters
- Optional task-service adapters
- Encrypted credential storage
- Signed macOS, Windows, and Linux packages
- Opt-in application updates
