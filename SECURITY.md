# Security policy

Daymark stores personal task data locally, so privacy and data integrity are
security concerns even though the application currently has no network service.

## Reporting a vulnerability

Please report security issues privately through the security-reporting feature
of the repository host once this repository is published. Do not open a public
issue containing exploit details, private task data, database files, home
directory paths, or other personal information.

Include the affected version, operating system, reproduction steps, and expected
impact. Reports involving data loss, unsafe file handling, packaging integrity,
or unintended network access receive priority.

## Supported versions

Until the first stable release, only the latest revision of `main` is supported.
